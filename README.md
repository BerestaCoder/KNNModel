# Модель K ближайших соседей
Данная модель предназначена для определения типа пользователя (айфон или андроид)на основе опроса 
Программа риеализована на языке Java. Структура проекта состоит из трёх файлов:
- App.java - Главный файл;
- KNearestNeighbors.java - Сама модель;
- Normalizer.java - Класс для нормализации параметров.
В корне проекта находятся входные данные (input.csv).
В главном файле можно редактировать такие переменные, как:
- TARGET_COL - Количество столбцов, упитывающихся при обучении модели;
- TOTAL_COLS - Количество всех столбцов;
- RANDOM_SEED - Стартовое число для случайного смешивания строк в датасете;
- NUMERIC_COLS - Список целочисленных столбцов.
В результате программа выводит в консоль результаты тестов с указанием точности предсказаний.
